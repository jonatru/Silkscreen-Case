# Silkscreen Case
This is a case for the open-source Silkscreen e-reader project: https://github.com/iandchasse/silkscreen-pcb/

### Hardware Required
* GDEY0426T82 e-paper display
* 503035 Lipo battery
* 4 M2x6 and 4 M2x8 socket head screws: https://a.co/d/05kvvuUn

### Print Settings
* Use 0.10mm layer height for best results
